    Команды

    Что такое команды?

    Команды — это специальные текстовые инструкции, позволяющие взаимодействовать с игрой. Вводя команды в чат, вы можете выполнять такие действия, как телепортация, создание существ или управление игроками. Команды обычно начинаются с /, за которым следует имя команды и необязательные аргументы.

    Кто может использовать команды?

    В настоящее время не существует команды, которую мог бы использовать игрок без прав администратора. В текущей версии доступны только команды администратора и RCON.

    Список команд

    Синтаксис команды

    /command_name <required_argument> [optional_argument={?}]

    <required_argument> → Должен быть включен.
    [optional_argument={?}] → Можно опустить. {?} указывает значение по умолчанию, которое используется, если оно опущено.

    Аргументы имеют разные типы. Наиболее распространенными являются strings, numbers, floats и booleans. Некоторые команды даже имеют сложные типы, например определенный filenames в специальном каталоге или фактически filter.

    Управление сервером
    /version

    Синтаксис: /version

    Описание: Показывает версию игры Palworld и версию PalDefender. RCON возвращает вывод JSON.

    Аргументы:

    • Нет

    Разрешения: Chat, RCON, Admin

    Пример: 

    /version

    /reloadcfg

    Синтаксис: /reloadcfg

    Описание: Перезагружает данные о запрете Config.json, WhiteList.json и PalDefender.

    Аргументы:

    • Нет

    Разрешения: Chat, RCON, Admin

    /reloadcfg

    /addadminip

    Аргументы:

    Разрешения: Chat, RCON, Admin

    • Нет

    Разрешения: Chat, RCON, Admin

    /iwantplayerlist

    /getpos

    Синтаксис: /getpos [UserId]

    Описание: Получает ваше текущее положение в мире, которое можно использовать для телепортации, призыва и подобных действий. Если указан [UserId], вместо этого получает позицию этого игрока.

    Аргументы:

    • [UserId]: (Необязательно) Идентификатор игрока, чью позицию вы хотите изменить get. Если опущено, получает вашу собственную позицию.

    Разрешения: Chat, RCON, Admin

    Пример:

/getpos steam_76500000000000000

    Аргументы:

    • <hour>: значение часа (0–23, день, ночь).

    Разрешения: Chat, RCON, Admin

    Пример: 

    /settime 12
/settime night

    /togglepvp

    Синтаксис: /togglepvp

    Описание: Включает и выключает сервер PvP для текущего сеанса.

    Аргументы:

    • Нет

    Разрешения: Chat, Admin

    Пример: 

    /togglepvp

    /alert

    Синтаксис: /alert <message>

    Описание: Отправляет предупреждающее сообщение всем игрокам на сервере. Это сообщение обычно отображается на видном месте на их экранах.

    Аргументы:

    • <message>: сообщение, которое будет транслироваться в качестве оповещения.

    Разрешения: Chat, RCON, Admin

    Пример: 

    /alert Server will restart in 5 minutes!

    /send

    Синтаксис: /send <type> <UserId> <Message>

    Описание: Позволяет отправить сообщение или сообщение журнала конкретному игроку.

    Аргументы:

    • <type>: тип отправляемого сообщения. Возможные значения:
      • msg: обычное сообщение в чате.
      • log: обычное сообщение журнала (белое, быстро исчезает, более крупный шрифт).
      • ilog: важное сообщение журнала (синее, сохраняется дольше).
      • vilog: Очень важное сообщение журнала (синее, сохраняется очень долго).
    • <UserId>: идентификатор игрока, получившего сообщение.
    • <Message>: текст сообщения для отправки.

    Разрешения: Chat, RCON, Admin

    Пример: 

    /send msg steam_76500000000000000 Dont miss out on Qonzer's sale!
/send log steam_76500000000000000 Dont miss out on Qonzer's sale!
/send ilog steam_76500000000000000 Dont miss out on Qonzer's sale!
/send vilog steam_76500000000000000 Dont miss out on Qonzer's sale!

    /resetoilrig

    Синтаксис: /resetoilrig <lv30|lv55|lv60|all>

    Описание: Сбрасывает выбранную нефтяную вышку или каждую управляемую в данный момент нефтяную вышку.

    Разрешения: Chat, активный статус администратора в игре.

    Пример: 

    /resetoilrig all

    /setting

    Синтаксис: /setting list [filter] или /setting <setting_name> <get|set|add|sub> [value].

    Описание: Проверяет или изменяет поддерживаемые текущие значения UPalGameSetting. Имена сопоставляются без учета регистра; принимается уникальный префикс или подстрока. Это экспериментальный вариант, который не заменяет постоянную конфигурацию мира, и клиенты могут продолжать отображать кэшированные значения.

    • list [filter]: списки поддерживаемых полей integer, float, логических, байтовых и перечисляемых.
    • get: считывает значение.
    • set: устанавливает любой поддерживаемый тип. Логические значения принимают true/false, on/off, yes/no или 1/0; перечисления принимают число или имя записи.
    • add / sub: изменяет только числовые значения.

    Разрешения: Chat, RCON, Admin

    Примеры: 

    /setting list death
/setting PalDeathPenaltyTime get
/setting PalDeathPenaltyTime set 10

    /resetbosstower

    Синтаксис: /resetbosstower <BossType|all>

    Описание: Команда, предназначенная только для отладки и сборки, сбрасывает один экземпляр башни босса или все сбрасываемые башни боссов. Одна цель должна использовать допустимое имя EPalBossType. Он недоступен в общедоступных сборках выпуска.

    Разрешения: Chat, RCON, Admin

    Пример: 

    /resetbosstower all

    /showbosses

    Синтаксис: /showbosses

    Описание: Команда интеллектуального анализа данных только для отладки и сборки, которая записывает статическую информацию текущего босса в PalDefender/Logs/BossInfo.json. Он недоступен в общедоступных сборках выпуска.

    Разрешения: Chat, RCON, Admin

    Управление базой
    /findunusedbases (alias: /findbases)

    Синтаксис: /findbases [empty|inactive|unused|all] [days=N] [builds<=N]

    Интерактивный синтаксис: /findbases visit [filters], /findbases next, /findbases kill [next]

    Описание: Сканирует пустые, неактивные или неиспользуемые по другим причинам базы. visit создает очередь просмотра только для чата и телепортируется к ее первому результату; next продвигается; kill уничтожает выбранную базу; kill next уничтожает его и продвигается вперед. Разрушение необратимо, поэтому сначала осмотрите каждую цель.

    • empty: нет рабочих и максимальное ограничение на количество зданий по умолчанию (или builds<=N).
    • inactive: в гильдии нет участников, и она неактивна как минимум days (по умолчанию 30).
    • unused: соответствует пустому или неактивному значению.
    • all: выводит список всех баз с применением явных фильтров.

    Разрешения: Листинг поддерживает Chat и RCON; visit/next/kill требует внутриигрового чата и разрешения администратора.

    Примеры: 

    /findbases empty builds<=5
/findbases inactive days=14
/findbases visit unused days=30
/findbases kill next

    /getnearestbase

    Синтаксис: /getnearestbase [X] [Y] [Z]

    Описание: Сообщает название гильдии, владеющей ближайшей к вашему персонажу базой.

    Примечание. При выполнении через RCON все параметры местоположения ([X] [Y] [Z]) обязательны, поскольку RCON не имеет персонажа игрока, который мог бы определить местоположение.

    Аргументы:

    • [X]: (Необязательно) координата X.
    • [Y]: (Необязательно) координата Y.
    • [Z]: (Необязательно) координата Z.

    Разрешения: Chat, RCON, Admin

    Пример: 

    /getnearestbase 100 200 50

    /gotonearestbase

    Синтаксис: /gotonearestbase [X] [Y] [Z]

    Описание: Телепортирует вас на ближайшую базу локации.

    Примечание. При выполнении через RCON все параметры местоположения ([X] [Y] [Z]) обязательны, поскольку RCON не имеет персонажа игрока, который мог бы определить местоположение.

    Аргументы:

    • [X]: (Необязательно) координата X.
    • [Y]: (Необязательно) координата Y.
    • [Z]: (Необязательно) координата Z.

    Разрешения: Chat, Admin

    Пример: 

    /gotonearestbase 100 200 50

    /killnearestbase

    Синтаксис: /killnearestbase [X] [Y] [Z]

    Описание: Уничтожает ближайшую базу (Использовать с осторожностью!).

    Примечание. При выполнении через RCON все параметры местоположения ([X] [Y] [Z]) обязательны, поскольку RCON не имеет персонажа игрока, который мог бы определить местоположение.

    Аргументы:

    • [X]: (Необязательно) координата X.
    • [Y]: (Необязательно) координата Y.
    • [Z]: (Необязательно) координата Z.

    Разрешения: Chat, RCON, Admin

    Пример: 

    /killnearestbase 100 200 50

    Управление игроками

    Синтаксис: /kick <UserId> [Reason="Kicked by Admin."]

    Описание: Удаляет игрока с сервера.

    Разрешения: Chat, RCON, Admin

    Персонаж игрока
    /tp

    Синтаксис: Любая из следующих работ:

    • /tp <UserId>
    • /tp <UserId1> <UserId2>
    • /tp <X> <Y>
    • /tp <X> <Y> <Z>
    • /tp <UserId> <X> <Y>
    • /tp <UserId> <X> <Y> <Z>
    • /tp home
    • /tp oilrig
    • /tp oilrig:Lv30
    • /tp oilrig:Lv55
    • /tp oilrig:Lv60

    Описание: Телепортирует вас или указанного игрока к другому игроку, координатам, ближайшей базе или месту назначения нефтяной вышки.

    Примечание. RCON должен включать телепортируемого игрока, поскольку RCON не имеет внутриигрового персонажа.

    Аргументы:

    • <UserId>: игрок, к которому телепортируется, или игрок, которого телепортируют, если указано больше аргументов.
    • <UserId1>: Игрок, которого нужно телепортировать.
    • <UserId2>: целевой игрок.
    • <X> <Y> [Z]: координаты карты. Если Z опущен, PalDefender пытается найти полезную высоту земли.
    • home: Телепортируется на ближайшую принадлежащую базу.
    • oilrig, oilrig:Lv30, oilrig:Lv55, oilrig:Lv60: телепортируется к месту назначения нефтяной вышки.

    Разрешения: Chat, RCON, Admin

    Пример: 

    /tp steam_76500000000000000 gdk_25300000000000000
/tp 100 -250
/tp oilrig:Lv60

    /deletepals

    Синтаксис: /deletepals <UserId> <PalFilter>

    Описание: Удаляет Pals у указанного пользователя с помощью расширенных фильтров. Фильтр позволяет указать несколько критериев (например, идентификатор Pal, уровень, пол, пассивные способности и т. д.) в одной команде. Пожалуйста, проверьте в безопасной среде перед использованием важных данных.

    Аргументы:

    <UserId>

    Описание: Идентификатор игрока, Pals которого будет удален.

    <PalFilter>

    Описание. Набор ключевых слов фильтра для выбора удаляемых Pals.

    Примечание. В одной команде можно объединить несколько ключевых слов.

    Доступные ключевые слова фильтра:

    • ID: PalID или список PalID (через запятую).
    • Nick: String (имя Pal)
    • Gender: male или female
    • Level: число, поддерживает символы <, >, <=, >=, =, !=.
    • Rank: число, поддерживает символы <, >, <=, >=, =, !=.
    • Lucky: true или false (блестящий)
    • Passives: PassiveSkill или список PassiveSkills (через запятую).
    • Limit: число (максимальное количество удаляемых Pals).

    Примеры фильтров:

    • ID Serpent, PinkLizard Level>10 Gender male Limit 3
    • ID Anubis Rank>=3
    • Passives CraftSpeed_up1,CraftSpeed_up2,Rare,PAL_CorporateSlave

    Клавиши фильтров и примеры, приведенные выше, являются текущим справочником PalFilter.

    Разрешения: Chat, RCON, Admin

    Пример: 

    /deletepals 76567890987654321 ID Serpent, PinkLizard Level>10 Gender male Limit 3
/deletepals 76567890987654321 ID Anubis Rank>=3
/deletepals 76561198033277828 Passives CraftSpeed_up1,CraftSpeed_up2,Rare,PAL_CorporateSlave

    /learntech

    Синтаксис: /learntech <UserId> <TechID>

    Описание: Позволяет игроку изучить определенную технологию. Используйте all, чтобы разблокировать все.

    Аргументы:

    Разрешения: Chat, RCON, Admin

    • <TechID>: Технология, которую стоит забыть. Используйте all, чтобы удалить все.

    Разрешения: Chat, RCON, Admin

    Пример:

/unlearntech steam_76500000000000000 all
