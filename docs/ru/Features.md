# Особенности и текущий статус

На этой странице представлены переключатели функций, ориентированных на пользователя, в PalDefender 1.9.1. Точные значения по умолчанию см. в [`Config.json`](./FileTypes/Config.md).

## Активная защита

- Обнаружения повреждений, выносливости, боеприпасов и дублирования базового лагеря можно переключать независимо.
- Anti-Vacuum блокирует подозрительные попытки дистанционного сбора обычных предметов, яиц Pal, реликвий и заметок. Администраторы обходят поддерживаемые проверки, если `allowAdminCheats` включен.
- Недействительный элемент, Pal-stat, Workbench-recipe, Doctor Surgi, Emergency-Respawn и другие проверки действий сервера остаются частью центрального уровня проверки.
- `BannedCampWorker` блокирует назначение настроенных идентификаторов персонажей на базе.

Устаревшая функция, управляемая ключами `antiDupe...`, скомпилирована из сборки текущего выпуска. Новый детектор дублирования базового лагеря является отдельным и управляется `baseCampDupeDetectionEnabled`.

## Администрация и мероприятия

- `/admingun` (`/agun`) предоставляет активному администратору защищенный внутриигровой [Admin Gun](./Commands/index.md).
- `/setting` может проверять или временно изменять поддерживаемые текущие настройки Palworld.
- `/findbases` предоставляет интерактивную очередь проверки для баз empty/inactive.
- PalSummons поддерживает имена встреч, элементы управления AI/damage-meter, множители статистики, условный захват, результаты рангов и настраиваемые награды. См. [`PalSummon.json`](./FileTypes/PalSummon.md).
- Направления Discord настраиваются в `PalWebhooks` и охватывают чат, команды, смерти, joins/leaves, вызовы, события на нефтяной вышке и обнаружение античитов.

## Сердцебиение

Релизные сборки отправляют контрольный сигнал на `https://pallink.net/api/heartbeat` каждые 10 секунд после того, как игра будет готова. Его полезная нагрузка содержит world/server GUID, код страны для локали ОС, версии PalDefender и Palworld, платформу Windows/Wine/Proton, время безотказной работы процесса и количество игроков online/maximum/unique-total. Он не включает имена игроков, идентификаторы учетных записей игроков, IP-адреса игроков, сообщения чата или содержимое сохранений. Он исключен из отладочных сборок.

## REST API

Аутентифицированный REST API поддерживает игрока, Pal, инвентарь, технологии, прогресс, гильдию, бан, обмен сообщениями, вознаграждение и модерацию. В версии 1.9.0 также добавлены [`POST /summon/pal`](./RESTAPI/Endpoints/summon-pal.md) и [`POST /summon/npc`](./RESTAPI/Endpoints/summon-npc.md).
