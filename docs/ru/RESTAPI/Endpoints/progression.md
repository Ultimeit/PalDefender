# GET /progression/{player_identifier}



**Конечная точка:** `GET /v1/pdapi/progression/<player_identifier>`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Progression.Read`

## Цель

Считывает значения прогресса игрока, такие как опыт, состояние, связанное с уровнем, общее количество реликвий и общее количество технологических очков.

## Параметры пути

- `player_identifier`: `UserId` или `PlayerUID` для целевого игрока.

## Параметры запроса

Нет.

## Тело запроса

Нет тела запроса.

## Схема ответа

--8<-- "_snippets/restapi/schemas/progression.md"

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |
| `400` | `INVALID_JSON` | Текст запроса был предоставлен, но его не удалось проанализировать как JSON. |
| `400` | `REQUEST_FAILED` | Не удалось определить целевого игрока, учетную запись, данные отдельных персонажей, данные записи или технологические данные. |
| `500` | `REQUEST_TIMEOUT` | Обратный вызов внутреннего игрового потока не завершился в течение 5 секунд. |

## Примеры

### Читать прогресс по идентификатору пользователя PS5

```http
GET /v1/pdapi/progression/ps5_c481a77e22004b9d
```

### Чтение прогресса по PlayerUID

```http
GET /v1/pdapi/progression/92b8f6ac-1a3d-4a9e-8f52-cc741db8c20a
```

## Сценарии

- Подтвердите текущие значения, прежде чем предоставлять прогресс.
- Проверьте действие поддержки после [POST /give/progression](give-progression.md).
- Создайте панель обзора игроков на доверенной панели администратора.
