# GET /banlist



**Конечная точка:** `GET /v1/pdapi/banlist`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Banlist.Read`

## Цель

Считывает записи о банах из списка банов. Данные, связанные с баном, хранятся в `Banlist.json`, а не в `Config.json`.

## Параметры пути

Нет.

## Параметры запроса

- `active`: `true`, `false` или `1` для фильтрации активного состояния.
- `entryType`: фильтрация по типу записи о запрете.
- `userId`: фильтрация по идентификатору пользователя.
- `ip` или `userIP`: фильтрация по IP-адресу.
- `issuerType`, `issuerName`, `issuerIP`: фильтрация по метаданным эмитента.
- `reason`: фильтрация по тексту причины.
- `q`: Общий текстовый поиск.

## Тело запроса

Нет тела запроса.

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |

## Примеры

### Список всех записей о банах

```http
GET /v1/pdapi/banlist
```

### Найти активные записи пользователя Steam

```http
GET /v1/pdapi/banlist?active=true&userId=steam_76561198012345678
```

### Поиск записей по IP

```http
GET /v1/pdapi/banlist?ip=203.0.113.42
```

## Сценарии

- Проверьте, забанен ли игрок или IP в данный момент.
- Прежде чем снимать бан, выполните поиск по причине или эмитенту.
- Создайте панель модерации, которая считывает данные от `Banlist.json` до API.
