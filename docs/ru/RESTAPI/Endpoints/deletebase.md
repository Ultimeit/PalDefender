# POST /deletebase/{base_camp_id}



**Конечная точка:** `POST /v1/pdapi/deletebase/<base_camp_id>`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Base.Delete`

## Цель

Удаляет base/camp по идентификатору базового лагеря. Это деструктивное действие администратора.

## Параметры пути

- `base_camp_id`: идентификатор базового лагеря, обычно копируется из данных guild/base.

## Параметры запроса

Нет.

## Тело запроса

Необязательный пустой JSON object. Подтвердите идентификатор перед отправкой запроса.

## Схема ответа

--8<-- "_snippets/restapi/schemas/deletebase.md"

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |
| `400` | `INVALID_JSON` | Текст запроса был предоставлен, но его не удалось проанализировать как JSON. |
| `400` | `REQUEST_FAILED` | Обратный вызов игрового потока вызвал исключение, или произошел сбой общего преобразователя player/resource. |
| `500` | `REQUEST_TIMEOUT` | Обратный вызов внутреннего игрового потока не завершился в течение 5 секунд. |
| `400` | `INVALID_BASE_CAMP_ID` | Значение пути `base_camp_id` не является допустимым GUID. |
| `500` | `BASE_CAMP_MANAGER_UNAVAILABLE` | Серверу не удалось получить доступ к `UPalBaseCampManager`. |
| `404` | `BASE_CAMP_NOT_FOUND` | Ни один базовый лагерь не соответствовал указанному GUID. |
| `500` | `DELETE_BASE_FAILED` | Базовый лагерь был найден, но destruction/cleanup не удалось. |

## Примеры

### Delete базовый лагерь GUID

```http
POST /v1/pdapi/deletebase/13b9e8d7-4f2c-42a1-b79e-fc2a9186e4d5
```

### Delete еще один базовый лагерь от GUID

```http
POST /v1/pdapi/deletebase/81c2f0a4-6d7e-49fb-a11d-0d2f9f94b13c
```

## Сценарии

- Удалите заброшенные или сломанные базы после проверки персонала.
- Используйте [GET /guilds](guilds.md) и [GET /guild](guild.md), чтобы определить правильный лагерь перед удалением.
- Не используйте эту конечную точку для плановой очистки, если ваш персональный процесс уже не проверит право собственности и не сделает резервные копии.
