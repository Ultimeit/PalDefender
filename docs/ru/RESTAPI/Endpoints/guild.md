# GET /guild/{guild_id}



**Конечная точка:** `GET /v1/pdapi/guild/<guild_id>`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Guild.Read`

## Цель

Возвращает одну гильдию с подробным описанием участников и информацией base/camp.

## Параметры пути

- `guild_id`: идентификатор гильдии, обычно копируется из [GET /guilds](guilds.md).

## Параметры запроса

Нет.

## Тело запроса

Нет тела запроса.

## Схема ответа

--8<-- "_snippets/restapi/schemas/guild.md"

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |
| `400` | `INVALID_JSON` | Текст запроса был предоставлен, но его не удалось проанализировать как JSON. |
| `400` | `REQUEST_FAILED` | Обратный вызов игрового потока вызвал исключение, или произошел сбой общего преобразователя player/resource. |
| `500` | `REQUEST_TIMEOUT` | Обратный вызов внутреннего игрового потока не завершился в течение 5 секунд. |
| `404` | `GUILD_NOT_FOUND` | Ни одна гильдия не соответствует указанному `guild_id`. |

## Примеры

### Читать список гильдий и лагерей

```http
GET /v1/pdapi/guild/f0a1c3e9-7d5b-4a28-8c33-411fdc2e6b74
```

### Прочитать другую гильдию от GUID

```http
GET /v1/pdapi/guild/92b8f6ac-1a3d-4a9e-8f52-cc741db8c20a
```
