# POST /give/items/{player_identifier}



**Конечная точка:** `POST /v1/pdapi/give/items/<player_identifier>`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Items.Give`

## Цель

Дает один или несколько предметов целевому игроку.

## Параметры пути

- `player_identifier`: `UserId` или `PlayerUID` для целевого игрока.

## Параметры запроса

Нет.

## Тело запроса

JSON object с `Items`, array даров на предметы. Для каждой записи требуется [`ItemID`](https://paldeck.cc/items) и положительный `Count`.

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |
| `400` | `INVALID_JSON` | Текст запроса был предоставлен, но его не удалось проанализировать как JSON. |
| `400` | `REQUEST_FAILED` | Обратный вызов игрового потока вызвал исключение, или произошел сбой общего преобразователя player/resource. |
| `500` | `REQUEST_TIMEOUT` | Обратный вызов внутреннего игрового потока не завершился в течение 5 секунд. |
| `400` | `INVALID_REQUEST` | Тело не содержит `Items` array. |
| `400` | `VALIDATION_FAILED` | Один или несколько грантов на предметы недействительны, не поддерживаются, слишком велики или не помещаются в инвентарь. |
| `500` | `GRANT_FAILED` | Проверка пройдена, но на сервере произошел сбой при добавлении элементов в инвентарь. |

## Примеры

### Передайте патроны и лаунчер игроку Steam.

```http
POST /v1/pdapi/give/items/steam_76561198012345678
```

```json
{
    "Items": [
        { "ItemID": "ExplosiveBullet", "Count": 500 },
        { "ItemID": "Launcher_Default_5", "Count": 1 }
    ]
}
```

### Дайте валюту игроку PS5

```http
POST /v1/pdapi/give/items/ps5_0f4b8c2d91aa34ef
```

```json
{
    "Items": [
        { "ItemID": "Money", "Count": 10000 }
    ]
}
```

## Сценарии

- Используйте для компенсационных пакетов после отката.
- Используйте для интеграции магазинов, где доверенная служба предоставляет приобретенные товары.
- Сначала проверьте [`ItemID`](https://paldeck.cc/items); отображаемые имена не всегда являются допустимыми идентификаторами.
