# GET /items/{player_identifier}



**Конечная точка:** `GET /v1/pdapi/items/<player_identifier>`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Items.Read`

## Цель

Перечисляет предметы целевого игрока. Идентификаторы элементов в ответах можно найти на [paldeck.cc/items](https://paldeck.cc/items).

## Параметры пути

- `player_identifier`: `UserId` или `PlayerUID` для целевого игрока.

## Параметры запроса

Нет.

## Тело запроса

Нет тела запроса.

## Схема ответа

--8<-- "_snippets/restapi/schemas/items.md"

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |
| `400` | `INVALID_JSON` | Текст запроса был предоставлен, но его не удалось проанализировать как JSON. |
| `400` | `REQUEST_FAILED` | Не удалось определить целевого игрока, состояние игрока, данные инвентаря или общий контейнер инвентаря. |
| `500` | `REQUEST_TIMEOUT` | Обратный вызов внутреннего игрового потока не завершился в течение 5 секунд. |

## Примеры

### Чтение инвентаря для игрока Steam

```http
GET /v1/pdapi/items/steam_76561198087654321
```

### Прочитать инвентарь игрока GDK.

```http
GET /v1/pdapi/items/gdk_2533274812345678
```

## Сценарии

- Проверьте инвентарь, прежде чем давать компенсацию.
- Подтвердите [`ItemID`](https://paldeck.cc/items) перед использованием [POST /give/items](give-items.md).
- Устранение неполадок с отчетами об отсутствующих элементах.
