# POST /unban/{user_id}



**Конечная точка:** `POST /v1/pdapi/unban/<user_id>`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Punishments.Unban`

## Цель

Разблокирует идентификатор пользователя в `Banlist.json`.

## Параметры пути

- `user_id`: идентификатор пользователя, которого нужно разблокировать.

## Параметры запроса

Нет.

## Тело запроса

Необязательное поле JSON: `Reason` string.

## Схема ответа

--8<-- "_snippets/restapi/schemas/unban.md"

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |
| `400` | `INVALID_JSON` | Текст запроса был предоставлен, но его не удалось проанализировать как JSON. |
| `400` | `REQUEST_FAILED` | Обратный вызов игрового потока вызвал исключение, или произошел сбой общего преобразователя player/resource. |
| `500` | `REQUEST_TIMEOUT` | Обратный вызов внутреннего игрового потока не завершился в течение 5 секунд. |
| `400` | `VALIDATION_FAILED` | Необязательное поле запроса имеет неверный тип JSON. |
| `404` | `BAN_NOT_FOUND` | Предоставленный `user_id` не заблокирован активно. |

## Примеры

### Разблокировать пользователя Steam

```http
POST /v1/pdapi/unban/steam_76561198012345678
```

```json
{
    "Reason": "Appeal accepted"
}
```

### Разблокировать пользователя PS5 по причине по умолчанию

```http
POST /v1/pdapi/unban/ps5_c481a77e22004b9d
```

```json
{}
```

## Сценарии

- Снимите бан пользователя после одобрения апелляции.
- Сохраняйте причину для контрольного журнала.
- Используйте [GET /banlist](banlist.md) с `userId` или `q`, чтобы проверить результат.
