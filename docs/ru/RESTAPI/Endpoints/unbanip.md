# POST /unbanip/{ip}



**Конечная точка:** `POST /v1/pdapi/unbanip/<ip>`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Punishments.UnbanIP`

## Цель

Разблокирует IP-адрес в `Banlist.json`.

## Параметры пути

- `ip`: IP-адрес для снятия блокировки.

## Параметры запроса

Нет.

## Тело запроса

Необязательное поле JSON: `Reason` string.

## Схема ответа

--8<-- "_snippets/restapi/schemas/unbanip.md"

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |
| `400` | `INVALID_JSON` | Текст запроса был предоставлен, но его не удалось проанализировать как JSON. |
| `400` | `REQUEST_FAILED` | Обратный вызов игрового потока вызвал исключение, или произошел сбой общего преобразователя player/resource. |
| `500` | `REQUEST_TIMEOUT` | Обратный вызов внутреннего игрового потока не завершился в течение 5 секунд. |
| `400` | `VALIDATION_FAILED` | Необязательное поле запроса имеет неверный тип JSON. |
| `404` | `BAN_NOT_FOUND` | Предоставленный `ip` не заблокирован активно. |

## Примеры

### Разбанить IP по причине

```http
POST /v1/pdapi/unbanip/203.0.113.42
```

```json
{
    "Reason": "Temporary block expired"
}
```

### Разблокировать IP по причине по умолчанию

```http
POST /v1/pdapi/unbanip/198.51.100.87
```

```json
{}
```

## Сценарии

- Снимите бан по IP после расследования.
- Используйте, когда игрок все еще заблокирован после разблокировки на уровне пользователя, поскольку запись IP остается активной.
- Используйте [GET /banlist](banlist.md) с `ip`, чтобы проверить результат.
