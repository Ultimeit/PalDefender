# POST /ReloadConfig



**Конечная точка:** `POST /v1/pdapi/ReloadConfig`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Reload.Config`

## Цель

Перезагружает конфигурацию PalDefender без необходимости полного перезапуска сервера.

## Параметры пути

Нет.

## Параметры запроса

Нет.

## Тело запроса

Необязательный пустой JSON object.

## Схема ответа

--8<-- "_snippets/restapi/schemas/reload-config.md"

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |

## Примеры

### Перезагрузить конфигурацию

```http
POST /v1/pdapi/ReloadConfig
```

### Перезагрузить после изменения токена

```http
POST /v1/pdapi/ReloadConfig
```

## Сценарии

- Примените изменения к поддерживаемым файлам конфигурации.
- Перезагрузите файл после обновления `Banlist.json`, правил импорта или других файлов PalDefender, доступных для чтения во время выполнения.
- Если изменение не вступит в силу после перезагрузки, перезапустите сервер во время периода обслуживания.
