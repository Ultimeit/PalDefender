# GET /pals/{player_identifier}



**Конечная точка:** `GET /v1/pdapi/pals/<player_identifier>`

**Аутентификация:** Токен носителя

**Разрешение:** `REST.Pals.Read`

## Цель

Перечисляет Pals целевого игрока. Идентификаторы Pal в ответах можно искать на [paldeck.cc/pals](https://paldeck.cc/pals).

## Параметры пути

- `player_identifier`: `UserId` или `PlayerUID` для целевого игрока.

## Параметры запроса

Нет.

## Тело запроса

Нет тела запроса.

## Схема ответа

--8<-- "_snippets/restapi/schemas/pals.md"

## Реакции на ошибки

Тела ошибок используют следующую форму:

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP | Код ошибки | Когда это произойдет |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | Заголовок `Authorization` отсутствует, имеет неправильный формат или не соответствует настроенному токену носителя. |
| `403` | `MISSING_PERMISSION` | Токен действителен, но не включает это разрешение конечной точки. |
| `400` | `INVALID_JSON` | Текст запроса был предоставлен, но его не удалось проанализировать как JSON. |
| `400` | `REQUEST_FAILED` | Обратный вызов игрового потока вызвал исключение, или произошел сбой общего преобразователя player/resource. |
| `500` | `REQUEST_TIMEOUT` | Обратный вызов внутреннего игрового потока не завершился в течение 5 секунд. |
| `404` | `PLAYER_NOT_FOUND` | Ни один онлайн-плеер не соответствует указанному `player_identifier`. |
| `404` | `PLAYER_STATE_NOT_FOUND` | Плеер существует, но его `APalPlayerState` недоступен. |

## Примеры

### Прочтите Pals для плеера PS5.

```http
GET /v1/pdapi/pals/ps5_0f4b8c2d91aa34ef
```

### Прочитайте Pals от PlayerUID

```http
GET /v1/pdapi/pals/6d2e8b40-73ef-4f11-9bb8-2e91a36e2f09
```

## Сценарии

- Проверьте игрока перед действиями поддержки.
- Убедитесь, что вознаграждение Pal получено после использования [POST /give/pals](give-pals.md) или [POST /give/paltemplate](give-paltemplate.md).
- Изучите сообщения об отсутствующем или неожиданном Pals.
