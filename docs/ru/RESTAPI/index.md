# PalDefender REST API

В этом разделе описан встроенный PalDefender REST API (небольшой интерфейс HTTP, предназначенный для **локального/доверенного** использования).

- **Базовый URL-адрес по умолчанию:** `http://127.0.0.1:17993`
- **Аутентификация:** Токен носителя (требуется на всех конечных точках).
- **Конечная точка версии:** `/v1/pdapi/version`

> Примечание по безопасности: **не** предоставляйте доступ к этому порту напрямую общедоступному Интернету. Если вам нужен удаленный доступ, используйте обратный прокси-сервер и надлежащие средства управления доступом.
