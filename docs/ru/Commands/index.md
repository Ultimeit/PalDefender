# Команды

## Что такое команды?

Команды — это специальные текстовые инструкции, позволяющие взаимодействовать с игрой. Вводя команды в чат, вы можете выполнять такие действия, как телепортация, создание существ или управление игроками. Команды обычно начинаются с <span class="var-command">/</span>, за которым следует имя команды и необязательные аргументы.

## Кто может использовать команды?

**В настоящее время не существует команды, которую мог бы использовать игрок без прав администратора.**
В текущей версии доступны только команды администратора и RCON.

## Список команд

!!! note "Синтаксис команды"
    <span class="var-command">/command_name&nbsp;</span><span class="var-command-arg">&lt;required_argument&gt;&nbsp;</span><span class="var-command-optional">[optional_argument={?}]</span>
    <br>
    <br>
    <p>
    <span class="var-command-arg">&lt;required_argument&gt;</span> → Должен быть включен.<br>
    <span class="var-command-optional">[optional_argument={?}]</span> → Можно опустить. <span class="var-command-optional">{?}</span> указывает значение по умолчанию, которое используется, если оно опущено.
    </p>
    <p>
    Аргументы имеют разные типы. Наиболее распространенными являются <span class="var-string">strings</span>, <span class="var-number">numbers</span>, <span class="var-float">floats</span> и <span class="var-bool">booleans</span>. Некоторые команды даже имеют сложные типы, например определенный <span class="file">filenames</span> в специальном каталоге или фактически <span class="var-filter">filter</span>.
    </p>

!!! tip "поиск по идентификатору"
    Используйте [paldeck.cc/pals](https://paldeck.cc/pals) для `PalID`, [paldeck.cc/items](https://paldeck.cc/items) для `ItemID`, [paldeck.cc/technology](https://paldeck.cc/technology) для `TechID`, [paldeck.cc/buildings](https://paldeck.cc/buildings) для `BuildingID`, [paldeck.cc/passives](https://paldeck.cc/passives) для `PassiveID` и [paldeck.cc/skills](https://paldeck.cc/skills) для идентификаторов навыков.

        **Описание:** Позволяет отправить сообщение или сообщение журнала конкретному игроку.

        - `<Message>`: текст сообщения для отправки.

        **Разрешения:** `Chat`, `RCON`, `Admin`

        **Пример:**
        ```
        /send msg steam_76500000000000000 Dont miss out on Qonzer's sale!
        /send log steam_76500000000000000 Dont miss out on Qonzer's sale!

    ??? info "/setting"
        **Синтаксис:** `/setting list [filter]` или `/setting <setting_name> <get|set|add|sub> [value]`.

        **Описание:** Проверяет или изменяет поддерживаемые текущие значения `UPalGameSetting`. Имена сопоставляются без учета регистра; принимается уникальный префикс или подстрока. Это экспериментальный вариант, который не заменяет постоянную конфигурацию мира, и клиенты могут продолжать отображать кэшированные значения.

        - `list [filter]`: списки поддерживаемых полей integer, float, логических, байтовых и перечисляемых.
        - `get`: считывает значение.
        - `set`: устанавливает любой поддерживаемый тип. Логические значения принимают `true/false`, `on/off`, `yes/no` или `1/0`; перечисления принимают число или имя записи.
        - `add` / `sub`: изменяет только числовые значения.

        **Разрешения:** `Chat`, `RCON`, `Admin`

        **Примеры:**
        ```
        /setting list death
        /setting PalDeathPenaltyTime get
        /setting PalDeathPenaltyTime set 10
        ```

??? note "Управление базой"
    ??? info "/findunusedbases (alias: /findbases)"
        **Синтаксис:** `/findbases [empty|inactive|unused|all] [days=N] [builds<=N]`

        **Интерактивный синтаксис:** `/findbases visit [filters]`, `/findbases next`, `/findbases kill [next]`

        **Описание:** Сканирует пустые, неактивные или неиспользуемые по другим причинам базы. `visit` создает очередь просмотра только для чата и телепортируется к ее первому результату; `next` продвигается; `kill` уничтожает выбранную базу; `kill next` уничтожает его и продвигается вперед. Разрушение необратимо, поэтому сначала осмотрите каждую цель.

        - `empty`: нет рабочих и максимальное ограничение на количество зданий по умолчанию (или `builds<=N`).
        - `inactive`: в гильдии нет участников, и она неактивна как минимум `days` (по умолчанию `30`).
        - `unused`: соответствует пустому или неактивному значению.
        - `all`: выводит список всех баз с применением явных фильтров.

        **Разрешения:** Листинг поддерживает `Chat` и `RCON`; visit/next/kill требует внутриигрового чата и разрешения администратора.

        **Примеры:**
        ```
        /findbases empty builds<=5
        /findbases inactive days=14
        /findbases visit unused days=30
        /findbases kill next
        ```

    ??? info "/getnearestbase"

        - `[Y]`: (Необязательно) координата Y.
        - `[Z]`: (Необязательно) координата Z.

        **Разрешения:** `Chat`, `RCON`, `Admin`

        ```
        /getnearestbase 100 200 50

    ??? info "/deletepals"
        **Синтаксис:** `/deletepals <UserId> <PalFilter>`

        **Описание:** Удаляет Pals у указанного пользователя с помощью расширенных фильтров. Фильтр позволяет указать несколько критериев (например, идентификатор Pal, уровень, пол, пассивные способности и т. д.) в одной команде. Пожалуйста, проверьте в безопасной среде перед использованием важных данных.

        **Аргументы:**

        ??? quote "<UserId\>"
            **Описание:** Идентификатор игрока, Pals которого будет удален.

        ??? quote "<PalFilter\>"
            **Описание.** Набор ключевых слов фильтра для выбора удаляемых Pals.

            **Примечание.** В одной команде можно объединить несколько ключевых слов.

            Доступные ключевые слова фильтра:

            - `ID`: PalID или список PalID (через запятую).
            - `Nick`: String (имя Pal)
            - `Gender`: `male` или `female`
            - `Level`: число, поддерживает символы `<`, `>`, `<=`, `>=`, `=`, `!=`.
            - `Rank`: число, поддерживает символы `<`, `>`, `<=`, `>=`, `=`, `!=`.
            - `Lucky`: `true` или `false` (блестящий)
            - `Passives`: PassiveSkill или список PassiveSkills (через запятую).
            - `Limit`: число (максимальное количество удаляемых Pals).

            **Примеры фильтров:**

            - `ID Serpent, PinkLizard Level>10 Gender male Limit 3`
            - `ID Anubis Rank>=3`
            - `Passives CraftSpeed_up1,CraftSpeed_up2,Rare,PAL_CorporateSlave`

            Клавиши фильтров и примеры, приведенные выше, являются текущим справочником PalFilter.

        **Разрешения:** `Chat`, `RCON`, `Admin`

        **Пример:**
        ```
        /deletepals 76567890987654321 ID Serpent, PinkLizard Level>10 Gender male Limit 3
        /deletepals 76567890987654321 ID Anubis Rank>=3
        /deletepals 76561198033277828 Passives CraftSpeed_up1,CraftSpeed_up2,Rare,PAL_CorporateSlave
        ```
