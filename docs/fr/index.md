## À propos

PalDefender implémente une validation complète côté serveur pour empêcher un large éventail de triches, d'exploits et de plantages connus et certains encore non découverts. Avant d'exécuter une action de joueur, PalDefender vérifie tout comportement de triche potentiel. Selon la configuration du serveur, les joueurs tentant de telles actions sont avertis, expulsés, bannis ou bannis IP. Actuellement, PalDefender est disponible pour les serveurs dédiés basés sur Windows.

**Tout développeur Linux expérimenté est invité à nous aider.**
