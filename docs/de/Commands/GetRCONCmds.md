# GetRCONCmds

## /getrconcmds { .toc-only }
??? info "/getrconcmds"
    **Syntax:** `/getrconcmds`

    **Beschreibung:** Gibt eine Liste aller per RCON nutzbaren Befehle inklusive benötigter Argumentanzahl zurück.

    **Argumente:**

    - None

    **Berechtigungen:** `RCON`

    **Beispiel:**
    ```
    /getrconcmds
    ```
