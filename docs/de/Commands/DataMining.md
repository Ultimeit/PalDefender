# Data mining

## /gettechids { .toc-only }
??? info "/gettechids"
    **Syntax:** `/gettechids`

    **Beschreibung:** Gibt eine Liste aller verfügbaren Technologie-IDs zurück. RCON erhält JSON-Ausgabe.

    **Argumente:**

    - None

    **Berechtigungen:** `Chat`, `RCON`, `Admin`

    **Beispiel:**
    ```
    /gettechids
    ```
