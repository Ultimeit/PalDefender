## 关于 PalDefender

PalDefender 实现了全面的服务端验证，用于防止大量已知以及部分未知的作弊、漏洞利用和崩溃问题。在执行任何玩家操作前，PalDefender 都会检查潜在的作弊行为。根据服务器配置，触发这些行为的玩家会被警告、踢出、封禁或 IP 封禁。目前 PalDefender 可用于基于 Windows 的专用服务器。

**欢迎有经验的 Linux 开发者帮助我们。**
