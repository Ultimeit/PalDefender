# 端点

> **认证:** Bearer 令牌（适用于下方所有端点）

> **基础路径:** `/v1/pdapi`

> **Content-Type:** `application/json`（用于 POST 请求）

| 方法                                                 | 端点                                         | 描述                   | 权限                                                                                                                                                                                                             | 详情                                             |
|--------------------------------------------------------|--------------------------------------------------|-------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------|
| GET | `/v1/pdapi/players`                              | 列出所有玩家。             | `REST.Players.Read`                                                                                                                                                                                                     | [GET /players](./players.md)                        |
| GET | `/v1/pdapi/player/<player_identifier>`           | 显示一个玩家。              | `REST.Player.Read`                                                                                                                                                                                                      | [GET /player](./player.md)                          |
| GET | `/v1/pdapi/pals/<player_identifier>`             | 列出玩家的帕鲁。         | `REST.Pals.Read`                                                                                                                                                                                                        | [GET /pals](./pals.md)                              |
| GET | `/v1/pdapi/items/<player_identifier>`            | 列出玩家的物品。        | `REST.Items.Read`                                                                                                                                                                                                       | [GET /items](./items.md)                            |
| GET | `/v1/pdapi/techs/<player_identifier>`            | 列出玩家的科技。 | `REST.Techs.Read`                                                                                                                                                                                                       | [GET /techs](./techs.md)                            |
| GET | `/v1/pdapi/progression/<player_identifier>`      | 显示进度值。      | `REST.Progression.Read`                                                                                                                                                                                                 | [GET /progression](./progression.md)                |
| GET | `/v1/pdapi/guilds`                               | 列出公会。                  | `REST.Guilds.Read`                                                                                                                                                                                                      | [GET /guilds](./guilds.md)                          |
| GET | `/v1/pdapi/guild/<guild_id>`                     | 显示一个公会。               | `REST.Guild.Read`                                                                                                                                                                                                       | [GET /guild](./guild.md)                            |
| GET | `/v1/pdapi/banlist`                              | 搜索封禁记录。           | `REST.Banlist.Read`                                                                                                                                                                                                     | [GET /banlist](./banlist.md)                        |
| GET | `/v1/pdapi/version`                              | 检查 API 状态和版本。     | `REST.Version.Read`                                                                                                                                                                                                     | [GET /version](./version.md)                        |

| POST | `/v1/pdapi/give/paltemplate/<player_identifier>` | 给予模板帕鲁。           | `REST.PalTemplates.Give`                                                                                                                                                                                                | [POST /give/paltemplate](./give-paltemplate.md)     |
| POST | `/v1/pdapi/give/paleggs/<player_identifier>`     | 给予帕鲁蛋。                | `REST.PalEggs.Give`                                                                                                                                                                                                     | [POST /give/paleggs](./give-paleggs.md)             |
| POST | `/v1/pdapi/give/progression/<player_identifier>` | 添加 EXP 和点数。           | `REST.Progression.Give`                                                                                                                                                                                                 | [POST /give/progression](./give-progression.md)     |
| POST | `/v1/pdapi/summon/pal` | 在坐标处生成 Pal。 | `REST.Summon.Pal` | [POST /summon/pal](./summon-pal.md) |
