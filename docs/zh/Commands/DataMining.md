# Data mining

## /gettechids { .toc-only }
??? info "/gettechids"
    **语法:** `/gettechids`

    **描述:** 返回所有可用科技 ID 的列表。RCON 会得到 JSON 输出。

    **参数:**

    - None

    **权限:** `Chat`, `RCON`, `Admin`

    **示例:**
    ```
    /gettechids
    ```
