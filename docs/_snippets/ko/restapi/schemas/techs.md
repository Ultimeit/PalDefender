### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Meta` | 객체 | 대상 플레이어의 기술 수 메타데이터입니다. |
| `Techs` | 객체 | 대상 플레이어의 기술 데이터입니다. |

`Meta` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `PlayerUID` | 문자열 | Palworld 저장 데이터에서 사용하는 플레이어 UID입니다. |
| `Player` | 문자열 | 요청 경로에 지정한 플레이어 식별자입니다. |
| `UnlockedCount` | 정수 | 현재 해금된 기술 수입니다. |
| `LockedCount` | 정수 | 현재 잠긴 기술 수입니다. |
| `TotalCount` | 정수 | 플레이어 데이터에 등록된 제작 기술의 총수입니다. |

`Techs` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Unlocked` | 문자열 배열 | 플레이어가 현재 배운 기술 ID입니다. |
