### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Meta` | 객체 | 길드 목록 메타데이터입니다. |
| `Guilds` | 객체 | 길드 UUID를 키로 하는 등록된 길드의 요약 정보입니다. |

`Meta` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `GuildCount` | 정수 | 반환한 길드 수입니다. |

길드 요약 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `name` | 문자열 | 길드 이름입니다. |
| `Level` | 정수 | 길드 거점 레벨입니다. |
| `admin` | 객체 | 길드 관리자의 상세 정보입니다. |
| `camp_count` | 정수 | 길드의 거점 수입니다. |
| `camps` | 객체 배열 | 거점 요약 정보입니다. |
| `member_count` | 정수 | 길드 멤버 수입니다. |
| `members` | 문자열 배열 | 길드 멤버의 PlayerUID 목록입니다. |

`admin` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `id` | 문자열 | 관리자의 PlayerUID입니다. |
| `name` | 문자열 | 관리자 플레이어 이름입니다. |

`camps[]` 항목 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `id` | 문자열 | 거점 GUID입니다. |
| `world_pos` | 객체 | 거점의 월드 좌표입니다. |
| `map_pos` | 객체 | 변환된 맵 좌표입니다. |

좌표 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `x` | 숫자 | X 좌표입니다. |
| `y` | 숫자 | Y 좌표입니다. |
| `z` | 숫자 | Z 좌표입니다. |
