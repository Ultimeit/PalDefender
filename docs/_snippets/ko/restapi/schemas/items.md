### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Meta` | 객체 | 대상 플레이어 메타데이터입니다. |
| `Inventory` | 객체 | 대상 플레이어의 인벤토리 컨테이너입니다. |

`Meta` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `PlayerUID` | 문자열 | Palworld 저장 데이터에서 사용하는 플레이어 UID입니다. |
| `Player` | 문자열 | 요청 경로에 지정한 플레이어 식별자입니다. |

`Inventory` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Items` | 객체 | 일반 인벤토리 컨테이너입니다. |
| `KeyItems` | 객체 | 중요 아이템 인벤토리 컨테이너입니다. |
| `Weapons` | 객체 | 장착 무기 인벤토리 컨테이너입니다. |
| `Armor` | 객체 | 방어구 인벤토리 컨테이너입니다. |
| `Food` | 객체 | 음식 인벤토리 컨테이너입니다. |
| `DropSlot` | 객체 | 드롭 슬롯 인벤토리 컨테이너입니다. |

인벤토리 컨테이너 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Available` | 불리언 | 컨테이너에 접근할 수 있었는지 나타냅니다. |
| `ContainerID` | 문자열 | Palworld 컨테이너 ID입니다. 사용할 수 없으면 빈 문자열입니다. |
| `UsedSlots` | 정수 | 사용 중인 슬롯 수입니다. |
| `MaxSlots` | 정수 | 전체 슬롯 수입니다. |
| `FreeSlots` | 정수 | 빈 슬롯 수입니다. |
| `Slots` | 객체 | 슬롯 인덱스를 키로 하는 사용 중인 슬롯 목록입니다. |

`Slots` 항목 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `ItemID` | 문자열 | Palworld 아이템 식별자입니다. |
| `Count` | 정수 | 슬롯의 스택 수량입니다. |
