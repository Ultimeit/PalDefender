### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Player` | 객체 | 플레이어 상세 정보입니다. |

`Player` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Name` | 문자열 | 현재 또는 저장된 플레이어 이름입니다. |
| `IP` | 문자열 | 플레이어 IP 주소입니다. 확인할 수 없으면 빈 문자열입니다. |
| `PlayerUID` | 문자열 | Palworld 저장 데이터에서 사용하는 플레이어 UID입니다. |
| `UserId` | 문자열 | 플랫폼 사용자 ID입니다. 확인할 수 없으면 빈 문자열입니다. |
| `GuildName` | 문자열 | 길드 이름입니다. 확인할 수 없으면 빈 문자열입니다. |
| `GuildUUID` | 문자열 | 길드 UUID입니다. 확인할 수 없으면 0으로 채운 GUID입니다. |
| `Status` | 문자열 | 저장된 플레이어 계정 상태입니다. |
| `WorldLocation` | 객체 | 현재 또는 마지막으로 저장된 월드 좌표입니다. |
| `MapLocation` | 객체 | 변환된 맵 좌표입니다. |

위치 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `x` | 숫자 | X 좌표입니다. |
| `y` | 숫자 | Y 좌표입니다. |
| `z` | 숫자 | Z 좌표입니다. |
