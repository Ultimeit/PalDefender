### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Version` | 객체 | PalDefender 버전 상세 정보입니다. |

`Version` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Major` | 정수 | 주 버전 번호입니다. |
| `Minor` | 정수 | 부 버전 번호입니다. |
| `Patch` | 정수 | 패치 버전 번호입니다. |
| `Build` | 정수 | 빌드 번호입니다. |
| `Version` | 문자열 | 짧은 버전 문자열입니다. |
| `VersionLong` | 문자열 | 전체 버전 문자열입니다. |
| `Beta` | 불리언 | 베타 빌드로 표시되어 있는지 나타냅니다. |
