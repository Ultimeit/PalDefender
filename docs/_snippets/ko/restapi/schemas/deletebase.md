### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `BaseCamp` | 객체 | 삭제된 거점의 요약 정보입니다. |
| `Deleted` | 객체 | 삭제한 거점 데이터의 정리 수량입니다. |
| `Archive` | 문자열 | 생성된 검토용 기록 보관 파일의 경로입니다. |

`BaseCamp` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Id` | 문자열 | 거점 GUID입니다. |
| `Summary` | 문자열 | 사람이 읽을 수 있는 거점 요약입니다. |

`Deleted` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `BaseCampPals` | 정수 | 삭제한 거점 팰 수입니다. |
| `StorageContainers` | 정수 | 비운 보관 컨테이너 수입니다. |
| `ItemStacks` | 정수 | 삭제한 아이템 스택 수입니다. |
| `ItemCount` | 정수 | 삭제한 아이템의 총수량입니다. |
| `Buildings` | 정수 | 삭제한 건축물 수입니다. |
| `DropItems` | 정수 | 삭제한 떨어진 아이템 액터 수입니다. |
| `DefenseModels` | 정수 | 삭제한 방어 모델 수입니다. |
| `OtherMapObjects` | 정수 | 삭제한 기타 맵 오브젝트 수입니다. |
| `PalBox` | 불리언 | 거점 팰 상자를 삭제했는지 나타냅니다. |
