### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Meta` | 객체 | 대상 플레이어 메타데이터와 팰 수입니다. |
| `Pals` | 객체 | 대상 플레이어의 보유 팰, 팰 상자 및 거점 팰입니다. |

`Meta` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `PlayerUID` | 문자열 | Palworld 저장 데이터에서 사용하는 플레이어 UID입니다. |
| `Player` | 문자열 | 요청 경로에 지정한 플레이어 식별자입니다. |
| `TeamCount` | 정수 | 플레이어가 데리고 있는 팰 수입니다. |
| `PalboxCount` | 정수 | 플레이어 팰 상자의 팰 수입니다. |
| `BaseCampCount` | 정수 | 포함된 거점 수입니다. |

`Pals` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Team` | 객체 | 팰 인스턴스 ID를 키로 하는 보유 팰 목록입니다. |
| `Palbox` | 객체 | 팰 인스턴스 ID를 키로 하는 팰 상자의 팰 목록입니다. |
| `BaseCamps` | 객체 배열 | 길드 거점과 배치된 작업 팰입니다. |

팰 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `PalID` | 문자열 | 팰 종 식별자입니다. |
| `UniqueNPCID` | 문자열 | 있는 경우 고유 NPC ID입니다. |
| `Nickname` | 문자열 | 사용자 지정 팰 별명입니다. 없으면 빈 문자열입니다. |
| `SkinId` | 문자열 | 스킨 ID입니다. 없으면 빈 문자열입니다. |
| `Gender` | 문자열 | 팰 성별입니다. |
| `Level` | 정수 | 팰 레벨입니다. |
| `Exp` | 정수 | 팰 경험치입니다. |
| `Shiny` | 불리언 | 희귀 팰인지 나타냅니다. |
| `PartnerSkillLevel` | 정수 | 파트너 스킬 등급입니다. |
| `CondensedPals` | 정수 | 농축 등급 진행도입니다. |
| `UnusedStatusPoints` | 정수 | 팰의 미사용 능력치 포인트입니다. |
| `FriendshipPoints` | 정수 | 친밀도 수치입니다. |
| `PhysicalHealth` | 문자열 | 신체 건강 상태입니다. |
| `WorkerSick` | 문자열 | 작업 팰의 질병 상태입니다. |
| `ImportedCharacter` | 불리언 | 가져온 캐릭터로 표시되어 있는지 나타냅니다. |
| `HP` | 숫자 | 현재 체력입니다. |
| `MP` | 숫자 | 있는 경우 현재 마나입니다. |
| `SP` | 숫자 | 있는 경우 현재 스태미나입니다. |
| `Shield` | 숫자 | 있는 경우 현재 실드 수치입니다. |
| `Hunger` | 숫자 | 현재 포만도입니다. |
| `MaxHunger` | 숫자 | 최대 포만도입니다. |
| `SAN` | 숫자 | SAN 수치입니다. |
| `Support` | 정수 | 지원 수치입니다. |
| `CraftSpeed` | 정수 | 제작 속도 수치입니다. |
| `PalSouls` | 객체 | `Health`, `Attack`, `Defense`, `CraftSpeed`를 포함하는 팰 영혼 강화 등급입니다. |
| `IVs` | 객체 | `Health`, `AttackMelee`, `AttackShot`, `Defense`를 포함하는 개체값입니다. |
| `ActiveSkills` | 문자열 배열 | 장착한 액티브 스킬입니다. |
| `LearntSkills` | 문자열 배열 | 배운 기술입니다. |
| `Passives` | 문자열 배열 | 패시브 스킬 ID입니다. |
| `ExtraWorkSuitabilities` | 객체 | 적성 ID를 키로 하는 추가 작업 적성 등급입니다. |
| `DisableWorkPreferences` | 문자열 배열 | 비활성화된 작업 선호 ID입니다. |
| `team_slot_index` | 정수 | 보유 팰 슬롯 인덱스입니다. `Team` 팰에만 포함됩니다. |
| `page` | 정수 | 팰 상자 페이지 인덱스입니다. `Palbox` 팰에만 포함됩니다. |
| `slot` | 정수 | 팰 상자 슬롯 인덱스입니다. `Palbox` 팰에만 포함됩니다. |
| `base_camp_slot_index` | 정수 | 거점 작업 팰 슬롯 인덱스입니다. 거점 팰에만 포함됩니다. |

`BaseCamps[]` 항목 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `id` | 문자열 | 거점 GUID입니다. |
| `level` | 정수 | 거점 레벨입니다. |
| `world_pos` | 객체 | 거점의 월드 좌표입니다. |
| `map_pos` | 객체 | 변환된 맵 좌표입니다. |
| `state` | 문자열 | 현재 거점 상태입니다. |
| `pals` | 객체 | 팰 인스턴스 ID를 키로 하는 거점 작업 팰 목록입니다. |

좌표 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `x` | 숫자 | X 좌표입니다. |
| `y` | 숫자 | Y 좌표입니다. |
| `z` | 숫자 | Z 좌표입니다. |
