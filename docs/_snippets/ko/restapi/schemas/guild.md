### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Guild` | 객체 | 길드 상세 정보입니다. |

`Guild` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `name` | 문자열 | 길드 이름입니다. |
| `Level` | 정수 | 길드 거점 레벨입니다. |
| `admin` | 객체 | 길드 관리자의 상세 정보입니다. |
| `member_count` | 정수 | 길드 멤버 수입니다. |
| `members` | 객체 배열 | 길드 멤버의 상세 기록입니다. |
| `camp_count` | 정수 | 길드의 거점 수입니다. |
| `camps` | 객체 배열 | 거점 상세 기록입니다. |
| `items` | 객체 | 길드 아이템 보관 데이터입니다. |
| `expeditions` | 객체 | 길드 원정 데이터입니다. |
| `laboratory` | 객체 | 길드 연구소 연구 데이터입니다. |

`admin` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `id` | 문자열 | 관리자의 PlayerUID입니다. |
| `name` | 문자열 | 관리자 플레이어 이름입니다. |

`members[]` 항목 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `player_uid` | 문자열 | 멤버의 PlayerUID입니다. |
| `player_name` | 문자열 | 멤버 플레이어 이름입니다. |
| `status` | 문자열 | 멤버 상태입니다. |

`camps[]` 항목 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `id` | 문자열 | 거점 GUID입니다. |
| `level` | 정수 | 거점 레벨입니다. |
| `world_pos` | 객체 | 거점의 월드 좌표입니다. |
| `map_pos` | 객체 | 변환된 맵 좌표입니다. |
| `state` | 문자열 | 현재 거점 상태입니다. |
| `pals` | 객체 | 팰 인스턴스 ID를 키로 하는 거점 작업 팰 목록입니다. |
| `buildings` | 문자열 | 현재 건축물 데이터의 자리표시자입니다. |

좌표 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `x` | 숫자 | X 좌표입니다. |
| `y` | 숫자 | Y 좌표입니다. |
| `z` | 숫자 | Z 좌표입니다. |

거점 팰 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `nickname` | 문자열 | 팰 별명입니다. |
| `pal_id` | 문자열 | 팰 종 식별자입니다. |
| `npc_id` | 문자열 | 고유 NPC ID입니다. |
| `skin_id` | 문자열 | 스킨 ID입니다. |
| `gender` | 문자열 | 팰 성별입니다. |
| `level` | 정수 | 팰 레벨입니다. |
| `shiny` | 불리언 | 희귀 팰인지 나타냅니다. |
| `phisical_health` | 문자열 | 현재 API가 반환하는 신체 건강 상태입니다. |
| `worker_sick` | 문자열 | 작업 팰의 질병 상태입니다. |
| `san` | 숫자 | SAN 수치입니다. |
| `imported` | 불리언 | 가져온 캐릭터로 표시되어 있는지 나타냅니다. |
| `friendship` | 정수 | 친밀도 수치입니다. |
| `active_skills` | 문자열 배열 | 장착한 액티브 스킬입니다. |
| `learnt_skills` | 문자열 배열 | 배운 기술입니다. |
| `passives` | 문자열 배열 | 패시브 스킬 ID입니다. |

`items` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `container_id` | 문자열 | 사용 가능한 경우 길드 아이템 컨테이너 ID입니다. |
| `current` | 정수 | 사용 중인 슬롯 수입니다. |
| `max` | 정수 | 전체 슬롯 수입니다. |
| `<slot_index>` | 객체 | 숫자 슬롯 인덱스를 키로 하는 슬롯 아이템 객체입니다. |

길드 아이템 슬롯 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `item_id` | 문자열 | 슬롯의 아이템 ID입니다. |
| `count` | 정수 | 슬롯의 스택 수량입니다. |

`expeditions` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `finished` | 정수 | 완료한 원정 수입니다. |
| `missions` | 객체 | 미션 ID를 키로 하는 해금된 미션 플래그입니다. |

`laboratory` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `current_research` | 문자열 | 현재 연구 ID입니다. |
| `researches` | 객체 | 연구 ID를 키로 하는 진행 중인 연구 정보입니다. |

연구 진행도 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `work_amount` | 숫자 | 현재 작업량입니다. |
| `required_work_amount` | 숫자 | 필요한 작업량입니다. |
| `percentage` | 숫자 | 현재 작업량을 필요한 작업량으로 나눈 값입니다. |
