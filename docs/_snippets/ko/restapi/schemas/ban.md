### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Success` | 불리언 | 차단이 기록되었으면 `true`입니다. |
| `UserId` | 문자열 | 차단된 사용자 ID입니다. |
| `IP` | 불리언 | 요청에서 IP 주소도 차단했는지 나타냅니다. |
| `BannedIP` | 문자열 | 차단된 IP 주소입니다. IP를 차단하지 않았다면 빈 문자열입니다. |
| `Kicked` | 정수 | 차단 작업으로 강제 퇴장된 접속 중인 플레이어 수입니다. |
