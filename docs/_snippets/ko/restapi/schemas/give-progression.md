### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Granted` | 객체 | 요청으로 지급한 성장 수치입니다. |
| `Totals` | 객체 | 해당하는 경우 지급 후 갱신된 재화 총량입니다. |

`Granted` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `EXP` | 정수 | 요청한 경우 지급한 경험치입니다. |
| `Relics` | 객체 | 요청한 경우 유물 유형별로 지급한 포인트입니다. |
| `TechnologyPoints` | 정수 | 요청한 경우 지급한 기술 포인트입니다. |
| `AncientTechnologyPoints` | 정수 | 요청한 경우 지급한 고대 기술 포인트입니다. |

`Totals` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Relics` | 객체 | `Relics`를 지급한 경우 갱신된 유물 유형별 포인트 총량입니다. |
| `TechnologyPoints` | 정수 | `TechnologyPoints`를 지급한 경우 갱신된 기술 포인트 총량입니다. |
| `AncientTechnologyPoints` | 정수 | `AncientTechnologyPoints`를 지급한 경우 갱신된 고대 기술 포인트 총량입니다. |
