### 200 응답 스키마

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Banlist` | 객체 | 쿼리 필터를 적용한 차단 목록 데이터입니다. |

`Banlist` 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Version` | 정수 | 차단 목록 파일 형식 버전입니다. |
| `BannedMessage` | 문자열 | 차단된 플레이어에게 표시할 메시지입니다. |
| `UserEntries` | 객체 배열 | 지정한 필터와 일치하는 사용자 차단 항목입니다. |
| `IPEntries` | 객체 배열 | 지정한 필터와 일치하는 IP 차단 항목입니다. |

`UserEntries[]` 항목 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `UserId` | 문자열 | 차단된 사용자 ID입니다. |
| `Active` | 불리언 | 차단이 현재 활성 상태인지 나타냅니다. |
| `BannedBy` | 객체 | 차단을 적용한 주체의 정보입니다. |
| `UnbannedBy` | 객체 | 차단 해제 주체의 정보입니다. 있는 경우에만 포함됩니다. |

`IPEntries[]` 항목 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `IP` | 문자열 | 차단된 IP 주소입니다. |
| `Active` | 불리언 | 차단이 현재 활성 상태인지 나타냅니다. |
| `BannedBy` | 객체 | 차단을 적용한 주체의 정보입니다. |
| `UnbannedBy` | 객체 | 차단 해제 주체의 정보입니다. 있는 경우에만 포함됩니다. |

Issuer 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `Type` | 문자열 | 제재 주체 유형입니다. 예: `rest`, `player`, `system`. |
| `NameValue` | 문자열 | 제재 주체의 이름, 사용자 ID, 토큰 또는 대체값으로 사용하는 유형입니다. |
| `IP` | 문자열 | 제재 주체의 IP 주소 메타데이터입니다. |
| `Reason` | 문자열 | 작업에 기록된 사유입니다. |
| `Timestamp` | 객체 | 작업 시각의 UTC 구성 요소입니다. |

Timestamp 객체 스키마:

| 필드 | 자료형 | 설명 |
|-------|------|-------------|
| `UTC` | 정수 | 초 단위 Unix 타임스탬프입니다. |
| `Year` | 정수 | UTC 연도입니다. |
| `Month` | 정수 | UTC 월입니다. |
| `Day` | 정수 | UTC 일입니다. |
| `Hour` | 정수 | UTC 시입니다. |
| `Min` | 정수 | UTC 분입니다. |
| `Sec` | 정수 | UTC 초입니다. |
| `Msec` | 정수 | 밀리초 부분입니다. |
