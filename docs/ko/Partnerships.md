## Qonzer
Qonzer는 전용 게임 서버 호스팅 전문 업체로, 성능과 투명성, 공정한 서비스, 유연한 서버 관리를 중시합니다.

> *Qonzer를 1년 넘게 이용해 왔고, 서비스에 매우 만족한다고 자신 있게 말씀드릴 수 있습니다.* <br>
> ~Zvend

### 파트너십 혜택
- **상시 15% 할인** – 신규 및 기존 고객 모두 프로모션 코드를 적용하여 주문한 새 서버의 모든 결제에서 15% 할인을 받습니다. 코드를 적용하지 않고 구매한 서버를 업그레이드해도 할인은 추가되지 않습니다. 혜택을 받으려면 코드를 적용하여 새 서버를 주문하세요.
- **클릭 한 번으로 PalDefender 활성화** – 서비스에 PalDefender가 기본 통합되어 있어 클릭 한 번이면 바로 활성화할 수 있습니다. 복잡한 설정은 필요 없습니다!
- **공식 PalDefender 테스트 서버** – Qonzer가 서버를 후원해 주었으며, 정식 운영에 활용할 날을 기대하고 있습니다.
- **추가 혜택 준비 중** – Qonzer와 긴밀히 협력하며 여러분의 Palworld 서버를 더욱 즐겁게 만들기 위해 노력하고 있습니다.

### **상시 15% 할인** 적용 방법 { #permanent-discount }

1. 제휴 링크로 접속하세요: <a href="https://qonzer.com/aff.php?aff=61" target="_blank">https://qonzer.com/aff.php?aff=61</a>
2. Game Servers(게임 서버) 메뉴에서 Palworld를 선택하세요.
3. Windows 서버를 선택하세요.
4. 서버 옵션을 설정한 뒤 Review & Checkout(주문 확인 및 결제)으로 이동하세요.
5. 프로모션 코드 `PalDefender`를 입력하고 결제를 완료하세요.
6. 이제 할인이 적용됩니다!

!!! important "중요"
    기존 고객도 이 혜택을 받을 수 있습니다. 다만 새 서버를 주문할 때 코드를 적용해야 합니다. 코드를 적용하지 않고 구매한 기존 서버를 업그레이드해도 할인은 추가되지 않습니다. `PalDefender` 코드를 적용하여 새 서버를 주문하세요.

**여러 서버에 할인을 적용하고 싶으신가요?** <br>
결제 전에 새 서버 여러 대를 장바구니에 넣고 주문에 프로모션 코드를 적용하면 됩니다.

### 다른 호스팅 업체를 이용 중인데 이전하고 싶다면

실시간 채팅에서 **PalDefender**를 통해 알게 되었다고 말씀하시고, 현재 이용 중인 호스팅 업체에서 이전하고 싶다고 알려 주세요.
Qonzer는 친절하고 공정한 업체로, 적절한 이전 방법이나 혜택을 함께 찾아 줄 것입니다.

저도 첫 달 요금에 큰 할인을 받았습니다!
