## 소개

PalDefender는 서버 측에서 다양한 검증을 수행하여 알려진 치트와 취약점 악용, 서버 충돌을 방지하며, 아직 발견되지 않은 일부 문제에도 대응합니다. 플레이어의 행동을 실행하기 전에 부정행위 가능성을 검사하고, 서버 설정에 따라 해당 플레이어에게 경고하거나 강제 퇴장, 계정 차단 또는 IP 차단을 적용합니다. 현재 PalDefender는 Windows 기반 전용 서버에서 사용할 수 있습니다.

**Linux 개발 경험이 풍부한 분들의 참여를 환영합니다.**
