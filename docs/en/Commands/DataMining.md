# Data mining

## /gettechids { .toc-only }
??? info "/gettechids"
    **Syntax:** `/gettechids`

    **Description:** Returns a list of all available technology IDs. RCON gets JSON output.

    **Arguments:**

    - None

    **Permissions:** `Chat`, `RCON`, `Admin`

    **Example:**
    ```
    /gettechids
    ```
