# PalDefender REST API

このセクションでは、組み込みの PalDefender REST API (**ローカル/信頼できる** 使用を目的とした小さな HTTP インターフェイス) について説明します。

- **デフォルトのベース URL:** `http://127.0.0.1:17993`
- **認証:** ベアラー トークン (すべてのエンドポイントで必要)
- **バージョンエンドポイント:** `/v1/pdapi/version`

> セキュリティ上の注意: このポートを公共のインターネットに直接公開しないでください**。リモート アクセスが必要な場合は、リバース プロキシと適切なアクセス制御を使用してください。
