# GET /version



**エンドポイント:** `GET /v1/pdapi/version`

**認証:** ベアラートークン

**許可:** `REST.Version.Read`

## 目的

このエンドポイントは、ツール、ダッシュボード、およびスクリプトのヘルス チェックとバージョン チェックとして使用します。

## パスパラメータ

なし。

## クエリパラメータ

なし。

## リクエストボディ

リクエスト本文がありません。

## エラー応答

エラー本体は次の形状を使用します。

```json
{
    "Error": {
        "Code": "ERROR_CODE",
        "Message": "Human-readable message",
        "Details": {}
    }
}
```

| HTTP |エラーコード |それが起こったとき |
|------|------------|-----------------|
| `401` | `INVALID_TOKEN` | `Authorization` ヘッダーが欠落しているか、形式が不正であるか、構成されたベアラー トークンと一致しません。 |
| `403` | `MISSING_PERMISSION` |トークンは有効ですが、このエンドポイント権限が含まれていません。 |

## 例

### ヘルスとバージョンのチェック

```http
GET /v1/pdapi/version
```

## シナリオ

- REST API トークンを構成した後に使用して、認証が機能することを確認します。
- ツールに最小 PalDefender バージョンが必要な場合は、エンドポイントを呼び出す前にこれを使用します。
- 最小の読み取り専用リクエストであるため、監視に使用します。
