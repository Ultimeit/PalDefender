# 📁 ファイルの種類

**PalDefender** は、サーバーの動作を構成し、その機能を拡張するために使用できるさまざまなカスタム ファイル タイプをサポートしています。
現在サポートされているもの:
* `Config.json`
* `WhiteList.json`
* `Banlist.json`
* `PalTemplate.json`
* `PalSummon.json`
* `Pals/ImportRules/*.json`
* `RESTAPI/RESTConfig.json`
* `RESTAPI/Tokens/*.json`

---

## ⚡ 概要

### 🛠️ [Config.json](./Config.md)

サーバーの動作、モデレーション、ログ記録、および管理設定を制御します。

* **セキュリティ:** アンチチート (警告、キック、禁止、IP 禁止)、名前/単語フィルタリング、SteamID 保護、不正なステータス/アイテム チェック。
* **ロギング:** チャット、RCON、ログイン、死亡、召喚、建設活動、石油掘削装置イベントを追跡します。
* **管理者:** IP ホワイトリスト、自動ログイン、ゴッドモード/チート、管理アクションの可視性。
* **お知らせ:** MOTD、プレイヤーの死亡、召喚、罰、戦利品イベント。
* **チャットとゲームプレイの制限:** メッセージの長さ、クールダウン バイパス、PvP/PvE のダメージ キャップ、木の伐採制限。
* **その他:** RCON Base64 サポート、起動失敗処理、オプションの中国語コマンド モード。

---

### 👥 `WhiteList.json`

サーバーへの参加を許可されるユーザーを定義します。
**ユーザー ID** と **IP アドレス** (マスクされた範囲を含む) の両方をサポートします。

---

### 🚫 `Banlist.json`

禁止、禁止解除、IP-禁止、および REST 罰則ツールで使用される PalDefender 禁止レコードを保存します。

* このファイルを手動で編集する代わりに、`/ban`、`/unban`、`/banip`、`/unbanip`、または REST API を使用してください。
* 手動で編集する必要がある場合は、最初にサーバーを停止するか、変更後に設定をリロードしてください。

---

### 🧬 [PalTemplate.json](./PalTemplate.md)

コマンドを介してカスタマイズされた Pals を生成したり指定したりするために使用されます。

* Pal の **ID、ニックネーム、性別、ステータス (HP/SP/MP)、空腹度、正気度、光沢のあるステータス、スキル、IV、パッシブ**などを定義します。
* Pal の **戦闘、ユーティリティ、作業特性**を完全にカスタマイズできます。

---

### 📍 [PalSummon.json](./PalSummon.md)

カスタム Pal を特定の場所に生成します。

* `PalTemplate` を参照し、**ワールド位置 (X、Y、Z)** を設定します。
* **捕獲不可**などのフラグを設定し、特定の**ステータス効果** (毒、溺死、火傷など) を無効にします。

---

### 🧾 [Pals/ImportRules/*.json](./PalImportRules.md)

カスタム Pal テンプレートを受け入れる方法を制御します。

* `Pals/ImportRules/Default.json` でグローバル制限を設定します。
* `Pals/ImportRules/Anubis.json` などのファイルを使用して、Pal ごとのオーバーライドを追加します。
* 制限値を超えた値をブロックするかクランプするかを選択します。
* 許可されていないパッシブがインポートをブロックするか削除するかを選択します。

---

### 🌐 REST API 構成ファイル

REST API 構成は `RESTAPI/RESTConfig.json` に存在し、ベアラー トークンは `RESTAPI/Tokens/*.json` に存在します。

* `RESTConfig.json` は、API が有効かどうか、バインド アドレス、ポート、コンソール ログ、および CORS 設定を制御します。
* 各トークン ファイルにはプライベート トークンとアクセス許可が含まれている必要があります。トークン値を公に共有しないでください。
