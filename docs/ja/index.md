## PalDefender について

PalDefender は、包括的なサーバー側検証を実装して、既知および未発見の広範なチート、エクスプロイト、クラッシュを防止します。プレイヤーのアクションを実行する前に、PalDefender は潜在的な不正行為がないかチェックします。サーバーの設定に応じて、そのようなアクションを試みたプレイヤーは警告、キック、禁止、または IP 禁止されます。現在、PalDefender は Windows ベースの専用サーバーで使用できます。

**経験豊富な Linux 開発者の方は、ぜひご協力ください。**
